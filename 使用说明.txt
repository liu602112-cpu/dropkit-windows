DropKit Windows 1.5.0 — 中文免安装版
=================================

启动：解压整个文件夹，双击 DropKit.exe。不要用管理员身份运行。
适用：Windows 10 / 11，.NET Framework 4.8（当前电脑已具备）。

Pinterest 网站素材
• 把 Pinterest 素材卡片或它的链接拖到工具，自动保存公开的视频、GIF 动图或原图。
• 如果播放器本身不能拖动，可拖素材卡片/链接，或在“文件暂存”点“网站”粘贴链接保存。
• 视频保存为 MP4；GIF 保留原文件动效；下载进度显示在窗口底部，完成后可复制或继续拖到 Eagle 等应用。
• 支持轮播素材，优先保存当前拖动的那一项视频；以前误存的封面重新拖入后会修正为视频，原图文件保留。
• 拖入与完成下载后的历史保存都在后台进行，窗口可以继续操作。
• 在剪贴板记录中选中视频后点“预览”，可以循环、静音播放，也能打开系统播放器。
• 素材目录：系统“图片”目录下的 DropKit\Pinterest；设置中可以直接打开。
• 重复导入校验并复用文件；保留原始网页来源，右键记录可“打开来源网页”。
• 仅保存可公开读取的资源；需要登录或仅提供流式播放的内容会保留链接并显示原因。
• 图片 Pin 只保存原图，不将封面误报为视频。单个素材最多 512 MB。
回收站删除与快捷键（1.5）
• 文件暂存：“全选”选中所有暂存项；“删除选中/全部删除”把原文件/文件夹移到回收站，包括引用的外部原文件。
• “仅移除”只取消暂存引用，文件保留。暂存列表支持 Ctrl+A、Delete。
• 剪贴板：“全部删除”处理全部历史，包含固定项；按条、按天删除同样移到回收站。
• 没有实体文件的文字/链接会生成文本副本，图片记录生成 PNG，再移到回收站；可恢复成文件。
• 删除后底部“回收站”可打开系统回收站恢复。回收站仍保留恢复副本，需要释放磁盘容量时可自行清空。
• 同一文件引用多次只回收一次；失败或占用的文件与对应记录保留；不会自动改为永久删除。
• F4：打开→收起→重新打开。彻底退出主程序后，启动器仍可用 F4 重开。
文件暂存
• 拖入文件或文件夹（含图片、视频文件），或点“添加”。多选时按住 Ctrl / Shift。
• 直接拖入图片数据或文字会保存到剪贴板历史；文件路径会加入文件暂存。拖拽时只验证，松开放入后才保存。
• 把选中的文件拖到资源管理器、桌面或接受文件的应用中。
• 默认以复制方式拖出；“删除选中/全部删除”会把原文件移到回收站，“仅移除”只取消暂存记录。
• 双击暂存项：在资源管理器中显示原文件。
• 暂存只保存原路径，不是备份；原文件被移动/删除后需重新添加。
• 拖着文件、图片、视频文件或文字时，较明显地左右晃动几次；确认存在可保存的拖拽内容后才唤出浮窗。
• “列表/网格”切换视图，“紧凑/展开”切换窗口大小。

剪贴板
• 从网页右键“复制图像/复制图片”，可连续收集不同的图片。
• “复制全部图片”：一次复制所有已收集图片，在电脑文件夹 Ctrl+V 即可保存。
• “保存全部图片…”：直接选择目标文件夹，整批保存（网页图片保存成 PNG，已有图片文件保留原格式）。
• 按住 Ctrl/Shift 可多选；“全选图片”选中当前筛选结果内的图片。
  多选后“复制选中”会复制这一批图片，“保存选中图片…”只导出所选部分。
• 可以直接把剪贴板中的单张或多张图片拖到桌面、文件夹、支持接收文件的应用。
• 图片记录和成组的图片文件都能多选复制、拖出；复制时会自动重试短暂占用。
• 单张网页图片同时提供 PNG、DIBV5、DIB 和图片文件，供不同软件读取。
• 聊天软件和编辑器对多文件粘贴支持不同；可试着直接从本窗口把图片拖入目标软件。
• 运行期间自动记录新复制的文本、链接、图片和文件。
• 打开时不会读取启动之前已在剪贴板里的内容。
• 搜索框实时筛选；“图片 / 文字 / 文件 / 固定”一键切换，文字包含链接。
• 双击 / Enter / Ctrl+C：复制所选内容。列表内 Ctrl+A：全选。
• 空格：预览；多张预览可用左右箭头切换。固定和 Delete 删除作用于全部选中记录；删除会移到回收站。
• “粘贴到原窗口”尝试回到唤出 DropKit 之前的窗口并粘贴。
  如果目标是管理员权限窗口，或该窗口不能接受粘贴，请手动 Ctrl+V。
• 固定项不会被数量和时间清理。可随时暂停/恢复记录。
• 图片最多 32 MB / 2000 万像素，文本最多 100 万字符；超限跳过。
• 普通历史默认保留 200 条、30 天，另有总容量 64 MB 上限。

快捷键与托盘
• Ctrl + Shift + S：文件暂存。
• F4：启动或打开剪贴板（无需按 Ctrl/Shift）。再次按 F4 收起窗口，再按重新打开。
• 程序在托盘或最小化时，F4 或再次双击 DropKit.exe 都会恢复剪贴板。
• 启动程序时会同时启用独立的 F4 启动器；退出剪贴板后，F4 仍可重新启动。
• Esc / 关闭窗口：收起到系统托盘，继续工作。
• 双击托盘图标打开剪贴板；右键图标可切换面板或退出剪贴板。
• “退出全部（停用 F4）”会同时停止启动器；之后需双击程序恢复。
• 如果快捷键被其他软件占用，设置页会提示，可通过托盘打开。
• 设置中打开“登录 Windows 时自动启动”（立即保存），会同时启动 F4 启动器和后台剪贴板。
  若之后移动程序位置，请先“退出全部”，从新位置打开并重新开启自启开关。
• 主程序和 F4 启动器是两个 DropKit 进程；启动器只负责按键，不读取剪贴板或历史。

文件夹收件箱
• 在设置选择一个文件夹并启用，新完成写入的文件会自动暂存。
• 仅监控该目录，不包含子目录，不导入之前已有文件。
• 跳过 .tmp、.part、.crdownload、.download 与 Office 临时文件。

数据与隐私
• 数据位置：%LOCALAPPDATA%\DropKitWindows\history.dat
• 使用当前 Windows 账户的 DPAPI 加密；普通剪贴板不上传、不云同步；仅主动保存 Pinterest 链接时联网下载。
• 默认排除常见密码管理器，并尊重 Windows 剪贴板保密标记。
• 普通网页/文本框中不带标记的密码无法自动识别，复制敏感内容前可暂停。
• 同一用户下运行的程序仍可能读取剪贴板或解密账户内数据；这不是密码保险库。
• 历史损坏时原始文件会保留为 .unreadable-*，不会悄悄覆盖唯一副本。
• 1.1 会修复旧版误保存成全透明的截图；修复前保留 history.dat.before-image-fix.bak 加密副本。
• 复制或拖出网页图片时，会在系统“图片”文件夹下的 DropKit 文件夹生成 PNG。
  可在设置中点“打开图片导出文件夹”查看；使用较短文件名，供 Eagle 等应用读取。
  旧记录引用 AppData 图片时，取出时会自动生成可读取的副本，不改动原记录。
  同一张图片重复取出会复用导出文件；退出程序后缓存仍保留，以供目标应用读取。
• 从资源管理器、Eagle 等复制的图片文件仍引用原路径，原文件移动或删除后需重新收集。
  这些主动导出的图片不再加密；“全部删除”会把关联文件及无引用的应用导出缓存移到回收站。
• 卸载：先在设置关闭开机启动，托盘选择“退出全部（停用 F4）”后删除程序文件夹。
  如需删除历史，可先在设置中“清空全部历史”，或退出后删除数据文件夹。

已知差异
• 这是基于原项目功能设计的 Windows 社区移植，非原作者官方 Windows 发布。
• macOS Quick Look 改为应用内预览；系统菜单栏改为 Windows 托盘。
• 普通鼠标晃动、框选文字或移动窗口不会唤出。只有实际拖出的可保存内容能通过验证；松开或 Esc 取消。
• Windows 对跨权限等级拖放有限制；请正常双击运行，不要以管理员身份启动。
• 使用系统 DPI 缩放；不同缩放比的多屏之间移动可能出现短暂模糊。
• 尚未在所有第三方应用和所有 Windows 版本逐一测试拖放/粘贴。
